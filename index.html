Retrieval quality starts with the evidence contract.

PaperPal preserves page offsets through chunking, reranking and context assembly. Page recall measures evidence retrieval; it cannot establish whether a generated answer is correct. A 1,200-token budget makes that boundary explicit.

An agent can answer well and still take the wrong route.

Fraud Investigation separates answer quality, task completion and routing. A policy question should not call transaction tools. A request to score a payment should not silently create a case. The 20 documented scenarios make those expectations inspectable.

Explore Fraud Investigation
A chronological split is only part of an evaluation.

Features must respect prediction time, and labels must finish before validation begins. Selection matters too: the credit-card project's thresholds and some features used the evaluated period. Vélib separates model promotion from serving; retail retention reserves a later final period.
